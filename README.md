# blind-nine — 무무 블라인드 나인

한 화면에서 두 명이 번갈아 하는 1~9 숫자 타일 추리 게임입니다.
각자 1~9 타일을 비공개로 한 장씩 내고, 큰 숫자가 이기되 **1은 9를 이깁니다**. 먼저 5승하면 승리합니다.

- `index.html` — 빌드 없이 바로 열리는 단일 파일 버전 (GitHub Pages로 배포, `.nojekyll`)
- [`REWRITE_GUIDE.md`](REWRITE_GUIDE.md) — 게임 룰·정보 공개 규칙·디자인 시스템·핵심 코드를 담은 재작성 가이드
